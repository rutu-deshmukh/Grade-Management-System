# Grade Management System

## Project Overview
This project is a console-based Java application that manages student grades.
It allows users to add student marks, calculate averages, assign grades, 
and generate performance reports.

## Features
- Add student marks
- Calculate average and grades
- View all students
- Search student by name
- Generate performance report
- Input validation (0–100)

## Technologies Used
- Java
- Arrays & 2D Arrays
- Scanner Class
- OOP Concepts

## How to Run
1. Open project in Eclipse
2. Run GradeManagementSystem.java
3. Use menu options
